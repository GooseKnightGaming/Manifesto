# HOW TO USE THIS INDEX

Britain Forward's policy documentation is organised in three tiers:

**Tier 1 — The Platform:** The full unified policy document. Start here. Contains all major policies in summary form with cross-references to sub-documents.

**Tier 2 — Sub-Documents:** Detailed policy frameworks for specific areas. Each is a standalone document going deeper than the platform allows.

**Tier 3 — Working Documents:** Attack analysis, additions under development, superseded drafts kept for reference.

Read the Platform first. Follow sub-document links for depth. Consult Attack Analysis before any public-facing activity.

# QUICK REFERENCE — KEY POLICY POSITIONS

*For rapid reference during interviews or debates.*

| Topic | Position | Key Points |
|---|---|---|
| Ideology | Sovereign Democracy — evidence not tribe | Not left, not right — acknowledged leanings in both directions |
| Nationalisation | Three-tier model | Public networks; majority public operating companies; private services |
| UBI | ~£100/week — pilot first | Net cost lower than gross; 5-year qualifying threshold; criminal suspension then resumption |
| Voting | Ranked Weighted + compulsory | NOTA available; fresh election if NOTA wins; coalition red lines stated |
| NHS | Sustained investment + prevention | Mental health parity; social care integration; pharmaceutical sovereignty |
| Housing | 100k social homes + new cities | Immediate + long-term; derelict buildings; cooperative housing |
